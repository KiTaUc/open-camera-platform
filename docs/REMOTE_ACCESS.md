# Безопасный удалённый доступ

Удалённый просмотр не должен делать камеру публичной. Рекомендуемый путь — подключаться к домашней сети через VPN либо открывать только веб-панель через отдельный HTTPS-шлюз. Порты RTSP и ONVIF камер не пробрасываются напрямую в интернет.

| Допустимо | Недопустимо |
| --- | --- |
| VPN до домашней сети | Открытый RTSP-порт камеры |
| HTTPS-шлюз к панели с аутентификацией | Публикация пароля камеры в URL или журнале |
| Отдельные роли пользователя | Общая учётная запись для всех |
