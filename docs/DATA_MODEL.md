# Модель данных

| Сущность | Ключевые поля | Назначение |
| --- | --- | --- |
| Камера | идентификатор, название, адрес, режим подключения, владелец | Представляет добавленное сетевое устройство. |
| Профиль потока | камера, имя профиля, RTSP URL без секретов, кодек, разрешение | Позволяет выбрать основной или экономичный поток. |
| Секрет камеры | камера, зашифрованные учётные данные | Хранится только на локальном узле записи. |
| Задание записи | камера, профиль, состояние, путь хранения | Управляет непрерывной или плановой записью. |
| Сегмент архива | камера, начало, окончание, путь, размер, контрольная сумма | Один неизменяемый фрагмент локального архива. |
| Событие | камера, время, тип, уровень, детали | Журнал обнаружения, ошибок потока и действий пользователя. |

Пароль камеры не выдаётся через API списка камер и никогда не показывается в веб-интерфейсе после сохранения.
