# Границы версии 0.1.0

Версия 0.1.0 — это открытый технический фундамент, а не замена готовому коммерческому приложению целиком.

| Готово | Следующий этап |
| --- | --- |
| Русская веб-панель добавления камеры | Автоматический ONVIF WS-Discovery |
| Проверка локальных RTSP/HTTP(S) адресов | Защищённое локальное хранение учётных данных камеры |
| API списка и добавления камер | Непрерывный процесс записи через медиадвижок |
| План сегментной RTSP-записи | Просмотр и управление архивными сегментами |
| Тесты и CI | Уведомления о движении и роли пользователей |

Ни одна функция версии 0.1.0 не должна использоваться для доступа к чужим камерам или обхода закрытых облачных протоколов производителей.
