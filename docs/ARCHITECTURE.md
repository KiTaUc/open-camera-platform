# Архитектура первого выпуска

## Назначение

Платформа позволяет пользователю добавить совместимую Wi‑Fi/IP-камеру, просматривать поток в веб-панели и сохранять записи на собственный диск. Обязательного облака производителя нет.

## Поддержка первого выпуска

| Возможность | Первый выпуск |
| --- | --- |
| Обнаружение камеры | ONVIF WS-Discovery в локальной сети |
| Добавление камеры | ONVIF либо ручной RTSP URL |
| Потоки | RTSP; профиль камеры и адрес хранятся отдельно от пароля |
| Запись | Сегменты на диск или подключённое сетевое хранилище |
| Архив | Метаданные камеры, сегмента, начала и окончания записи |
| Доступ | Локальная веб-панель с учётными записями |

## Границы безопасности

Пароли камер не попадают в браузер, журнал приложения или репозиторий. Внешний доступ строится через отдельный защищённый VPN/туннель; приложение не открывает RTSP-адреса камер напрямую в интернет. Закрытые P2P-камеры без ONVIF и RTSP не считаются поддерживаемыми.

## Компоненты

1. **Веб-панель** управляет камерами, просмотром и архивом.
2. **Сервис ONVIF** обнаруживает устройства и получает профиль потока.
3. **Сервис записи** принимает поток и сохраняет сегменты на собственный диск.
4. **База метаданных** хранит камеры, настройки без паролей и ссылки на сегменты.

Для реальной записи потоков требуется пользовательская установка с поддержкой системного медиадвижка. Поэтому открытый проект будет разделять веб-панель и локальный сервис записи, а не пытаться исполнять запись внутри браузера.
