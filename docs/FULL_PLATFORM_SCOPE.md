# Функциональный объём полной платформы

Полная версия развивает проект как локальную VMS/NVR-платформу для совместимых ONVIF/RTSP-камер. Основным стандартом потоков будет ONVIF Profile T: он охватывает H.264/H.265, настройки изображения, события движения и вмешательства, метаданные, двусторонний звук, PTZ и HTTPS-потоки для поддерживающих устройств.[1]

| Блок | Первый полноценный набор функций | Открытый стандарт |
| --- | --- | --- |
| Камеры | Автопоиск, ручное добавление, несколько профилей, PTZ при поддержке | ONVIF / RTSP |
| Просмотр | Сетка камер, основной и экономичный поток, снимки, аудио при поддержке | ONVIF Profile T |
| Запись | Непрерывная, по расписанию, по событию, ротация по сроку и объёму | Локальный медиадвижок + Profile G при поддержке камеры |
| Архив | Временная шкала, поиск, экспорт сегмента, политика хранения | Локальный архив / ONVIF Profile G |
| События | Движение, вмешательство, тревоги камеры, собственный детектор как резерв | ONVIF Profile T / M |
| Аналитика | Метаданные объектов, поиск событий, интеграция MQTT только при явном включении | ONVIF Profile M |
| Доступ | Роли, аудит действий, локальный доступ; удалённый доступ только через отдельный VPN/туннель | Локальная сеть |

## Принцип совместимости

Поддержка зависит от реально заявленных профилей конкретной камеры. Profile T покрывает развитый поток и события, Profile M — аналитические метаданные и события, а Profile G — управление и получение записей с edge-устройств.[1] [2] [3] Камеры, которые предоставляют только закрытое P2P-облако, не считаются совместимыми, если не выдают ONVIF или RTSP.
