# Проверка первого выпуска

19 августа 2026 года выполнен сквозной сценарий через браузер.

1. Открыта русскоязычная веб-панель.
2. В форму введены название «Тестовая камера», режим ONVIF и локальный RTSP-адрес `rtsp://192.168.1.30/live`.
3. После отправки форма очистилась, а камера появилась в списке.

Проверка использовала фиктивный адрес из приватного диапазона и не подключалась к реальному устройству.

## Проверка локального ONVIF-поиска

После добавления ручной кнопки поиска панель выполнила короткий WS-Discovery запрос только в тестовой локальной сети. Устройства не были найдены, и интерфейс корректно вывел сообщение «Совместимые ONVIF-камеры не найдены». Это ожидаемый результат для изолированной среды без камеры.
