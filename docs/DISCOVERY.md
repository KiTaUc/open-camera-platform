# Безопасное обнаружение ONVIF-камер

ONVIF-обнаружение в следующем выпуске использует WS-Discovery только в локальной сети. В режиме ad hoc клиент отправляет multicast Probe, а подходящие устройства отвечают непосредственно отправителю. Стандарт также предусматривает объявление устройств при подключении к сети, поэтому сервис может регистрировать появление устройств без постоянного сканирования.[1]

## Ограничения реализации

1. Поиск запускается только явным действием владельца панели и имеет короткий таймаут.
2. Multicast-трафик ограничен локальным интерфейсом; внешние адреса и интернет-сканирование запрещены.
3. Результат обнаружения показывает только идентификатор устройства и адрес службы; проверка учётных данных выполняется отдельно.
4. Обнаружение не означает совместимость потока: пользователь всё равно выбирает ONVIF-профиль или вручную задаёт RTSP URL.
