# Постоянный локальный сервис

Полная платформа состоит из веб-панели и постоянно работающего локального сервиса на компьютере, NAS или мини‑ПК пользователя. Такой сервис необходим для непрерывного приёма RTSP-потоков, хранения архива и своевременной обработки событий; браузер сам по себе не может надёжно выполнять эти задачи.

| Компонент | Ответственность | Данные |
| --- | --- | --- |
| Диспетчер камер | Запускает и останавливает поток для каждой включённой камеры | Конфигурация камеры без пароля в журнале |
| Процесс записи | Передаёт RTSP-поток медиадвижку и создаёт сегменты | Локальные файлы архива |
| Индекс архива | Учитывает начало, окончание, размер и источник сегментов | Локальная БД метаданных |
| Обработчик событий | Принимает ONVIF-события и формирует локальные события платформы | Журнал событий |
| Политика хранения | Удаляет только старые сегменты по правилам владельца | Сегменты, превышающие срок/лимит |

## Безопасное выполнение

Сервис запускается в домашней сети пользователя. Учётные данные камер хранятся локально и выдаются только процессу подключения; они не возвращаются веб-панели. Удалённый доступ не должен открывать RTSP-порты камер: для него используется отдельный VPN или защищённый туннель, настроенный владельцем.

## Границы первого полноценного сервиса

Сервис не использует облако производителя, не пытается обходить закрытые P2P-протоколы и не сканирует интернет. Он принимает только камеры, которые пользователь добавил сам или обнаружил в собственной локальной сети.
