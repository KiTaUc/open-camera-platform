# Открытая платформа камер

Открытый первый выпуск веб-панели для подключения совместимых Wi‑Fi/IP-камер без обязательного платного облака производителя.

## Что уже реализовано

Панель позволяет добавить ONVIF или RTSP-камеру из локальной сети, получить список зарегистрированных камер и применять безопасные проверки адресов. RTSP/HTTP(S)-адреса за пределами локальной сети по умолчанию отклоняются. В проект включены модель сегментов архива, API добавления камер и русскоязычный интерфейс.

## Быстрый запуск

Требуется Node.js 22 или новее.

```bash
npm test
npm start
```

После запуска откройте `http://localhost:8787` на компьютере, который находится в одной сети с камерой.

## Совместимость

Первый выпуск ориентирован на ONVIF и RTSP. Устройства, работающие исключительно через закрытое P2P-облако производителя и не предоставляющие ONVIF/RTSP, не гарантированно поддерживаются.

## Безопасность

Не открывайте RTSP-порты камер напрямую в интернет. Для удалённого просмотра используйте отдельный VPN или защищённый туннель. Не добавляйте реальные пароли камер в issue, пример данных или репозиторий.

## План развития

Следующие этапы: автоматическое ONVIF-обнаружение, защищённое хранение учётных данных на локальном узле, сервис записи потоков, сегменты архива и просмотр записей.

Ядро уже содержит проверяемый план сегментной записи RTSP через системный медиадвижок `ffmpeg`. Для запуска реальной записи сам пользователь устанавливает этот компонент на своём компьютере, NAS или мини‑ПК; веб-панель не загружает видео в чужое облако.

В обычном локальном запуске задания записи выполняет `ffmpeg`; в тестовом режиме вместо этого работает безопасная имитация диспетчера, поэтому автоматические тесты не обращаются к сетевым камерам.

Смотрите подробности в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) и [`docs/DATA_MODEL.md`](docs/DATA_MODEL.md).
